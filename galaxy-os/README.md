# Galaxy OS 1.0

브라우저에서 바로 동작하는 One UI 스타일 휴대전화 OS 시뮬레이터입니다. `index.html` 파일 하나로 되어 있어 설치나 서버 없이 열기만 하면 됩니다. (PC에서는 휴대폰 프레임, 휴대폰에서는 전체 화면)

## One UI 스타일 요소

- **접히는 큰 제목**: 앱 상단의 큰 제목이 스크롤하면 툴바로 접히고, 중간에서 멈추면 열림/닫힘으로 자동 정렬
- **홈 화면**: 시계·날씨 위젯, 좌우로 넘기는 페이지와 페이지 표시, 독, 위로 밀면 앱스 화면, 아래로 밀면 알림창
- **앱스 화면**: 좌우 페이지(4×6), 통합 검색(앱·연락처·노트·설정, 초성 검색), 아이콘 길게 누르기 메뉴
- **퀵 패널 2단계**: 한 번 내리면 버튼 6개와 알림, 한 번 더 내리면 Wi-Fi·블루투스 큰 버튼과 전체 빠른 설정, 밝기, 기기 제어
- **잠금화면**: 아무 방향으로 밀어서 해제(물결 효과), 알림 아이콘, 전화·카메라 바로가기는 밀어서 실행
- **측면 버튼 / 볼륨 버튼**: 측면 버튼 누르기 = 화면 끄기/켜기, 길게 누르기 = 전원 메뉴(전원 끄기·다시 시작), 볼륨 버튼 = One UI 볼륨 패널
- **엣지 패널**: 화면 오른쪽 핸들을 눌러 자주 쓰는 앱 실행
- **최근 앱**: 앱 미리보기 카드, 위로 밀어서 닫기, 모두 닫기
- 앱이 아이콘 위치에서 커지며 열리는 애니메이션, 날짜가 바뀌는 캘린더 아이콘, 바늘이 움직이는 시계 아이콘

## Galaxy 키보드

- 한글 두벌식 조합(겹받침·이중모음·받침 넘기기, 자모 단위 지우기), 영문, 기호 2페이지, 숫자 줄, 이모티콘
- 키 위의 작은 기호를 길게 눌러 입력(대체 문자), 키를 뗄 때 입력, 키 미리보기
- 툴바: 이모티콘 / 클립보드 / 음성 입력(브라우저 지원 시) / 설정 / 숨기기
- 키보드가 열리면 뒤로 버튼이 키보드 숨기기(∨)로 바뀜

## 클립보드

- 텍스트를 길게 누르거나 우클릭: 잘라내기 / 복사 / 붙여넣기 / 모두 선택 / 클립보드
- 키보드 클립보드 패널(눌러서 붙여넣기, 고정, 삭제), 클립보드 앱, 기기 클립보드와 연동

## 앱

전화, 메시지(자동 답장), 연락처, 노트, 계산기, 시계(알람·세계 시각·스톱워치·타이머), 캘린더, 갤러리, 카메라(실제 카메라), 날씨(Open-Meteo 실시간 날씨, 현재 위치), 설정, 클립보드, 인터넷

**설정**은 One UI 메뉴 구조를 따릅니다: 연결(Wi-Fi 목록), 소리 및 진동(소리 모드·음량), 알림, 디스플레이(라이트/다크·밝기·편안하게 보기·글자 크기), 배터리(실제 배터리), 배경화면 및 스타일(색상 팔레트), 홈 화면, 잠금화면, 디바이스 케어, 애플리케이션(앱 정보·강제 종료), 일반(키보드·24시간 형식·초기화), 접근성, 소프트웨어 업데이트, 휴대전화 정보, 설정 검색.

모든 데이터는 브라우저의 localStorage에 저장됩니다.

## 단축키 (PC)

- `Esc`: 뒤로
- 잠금 화면에서 `Enter` / `Space`: 잠금 해제
- 계산기 앱에서 숫자·연산자 키 입력
