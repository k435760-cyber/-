# Galaxy OS 1.0

브라우저에서 바로 동작하는 One UI 9.5 스타일 휴대전화 OS 시뮬레이터입니다. `index.html` 파일 하나로 되어 있어 설치나 서버 없이 열기만 하면 됩니다. (PC에서는 휴대폰 프레임, 휴대폰에서는 전체 화면)

## One UI 9.5 스타일

One UI 9.5는 아직 정식 출시 전이라(2027년 초 예상), 공개된 One UI 8.5/9 디자인과 9.5 유출 정보를 바탕으로 만들었습니다.

- **반투명 유리(frosted glass) 디자인**: 퀵 패널 타일, 떠 있는 탭 바, 알림, 토스트, 메뉴, 대화상자
- **떠 있는 알약형 탭 바**: 전화·시계·갤러리 하단의 아이콘 탭 바, 설정의 하단 검색창
- **편집 가능한 퀵 패널**: 버튼 추가·삭제·순서 변경, 크기 변경(작게/넓게), 밝기·음량 슬라이더 세로/가로 전환
- **잠금화면**: 배경화면 색에 맞춰 바뀌는 세로형 큰 시계, Now Bar(타이머·스톱워치·통화·다음 알람·날씨 요약)
- **앱 잠금**: 설정 › 보안 및 개인정보 보호 › 앱 잠금에서 PIN으로 앱 잠그기
- **부드러운 애니메이션**: 앱·앱스 화면이 열릴 때 홈 화면이 뒤로 물러나는 깊이 효과, 잠금 해제 시 확대 효과
- 단순해진 설정 슬라이더(One UI 9)

## One UI 기본 요소

- **접히는 큰 제목**: 앱 상단의 큰 제목이 스크롤하면 툴바로 접히고, 중간에서 멈추면 열림/닫힘으로 자동 정렬
- **홈 화면**: 시계·날씨 위젯, 좌우로 넘기는 페이지와 페이지 표시, 독, 위로 밀면 앱스 화면, 아래로 밀면 알림창
- **앱스 화면**: 좌우 페이지(4×6), 통합 검색(앱·연락처·노트·설정, 초성 검색), 아이콘 길게 누르기 메뉴
- **퀵 패널 2단계**: 한 번 내리면 버튼 6개와 알림, 한 번 더 내리면 Wi-Fi·블루투스 큰 버튼과 전체 빠른 설정, 밝기, 기기 제어
- **잠금화면**: 아무 방향으로 밀어서 해제(물결 효과), 알림 아이콘, 전화·카메라 바로가기는 밀어서 실행
- **측면 버튼 / 볼륨 버튼**: 측면 버튼 누르기 = 화면 끄기/켜기, 길게 누르기 = 전원 메뉴(전원 끄기·다시 시작), 볼륨 버튼 = One UI 볼륨 패널
- **엣지 패널**: 화면 오른쪽 핸들을 눌러 자주 쓰는 앱 실행
- **최근 앱**: 앱 미리보기 카드, 위로 밀어서 닫기, 모두 닫기
- 앱이 아이콘 위치에서 커지며 열리는 애니메이션, 날짜가 바뀌는 캘린더 아이콘, 바늘이 움직이는 시계 아이콘

## Galaxy AI

설정 › Galaxy AI에서 Anthropic API 키(console.anthropic.com)를 연결하면 Claude(기본 Claude Opus 5.5, Sonnet 5.5·Haiku 5.5 선택 가능)로 동작합니다. 키는 이 브라우저에만 저장되고, 요청은 브라우저에서 Anthropic API로 바로 전송됩니다(공식 `@anthropic-ai/sdk` 사용).

- **AI 어시스턴트**: 측면 버튼 길게 누르기(또는 퀵 패널 Galaxy AI). "7시 30분 알람 맞춰줘", "5분 타이머", "다크 모드 켜줘", "오늘 브리핑", "계산기 열어줘" 같은 명령은 키 없이 기기에서 처리하고, 그 밖의 질문은 Claude가 답함
- **서클 투 서치**: 홈 버튼을 길게 누르고 화면의 아무 곳에나 동그라미를 그리면 그 안의 글자를 인식해 AI 개요·웹 검색·번역·복사
- **채팅 어시스트**: 키보드 ✦ 버튼 → 문체 변경(전문적·캐주얼·정중하게·소셜 미디어·이모티콘), 맞춤법 검사, 번역 후 바로 적용
- **노트 어시스트**: 노트 편집 화면 ✦ → 요약, 자동 서식, 맞춤법 교정, 번역, 핵심 정리 표
- **메시지 답장 제안**: 대화 화면 ✦ → 답장 3개 제안, 대화 요약
- **포토 어시스트**: 갤러리 사진 → AI 편집 → 수채화·만화·스케치·빈티지·네온·팝아트 스타일로 새 사진 저장("AI 생성" 워터마크, 기기 내 처리)
- **통역 앱**: 위아래로 마주 보고 쓰는 실시간 통역(음성 인식 + 번역 + 음성 출력)

API 키가 없어도 기기 명령, 노트 요약/서식(간단한 기기 내 처리), 포토 어시스트, 번역(MyMemory 무료 번역)은 사용할 수 있습니다.

## Galaxy 키보드

- 한글 두벌식 조합(겹받침·이중모음·받침 넘기기, 자모 단위 지우기), 영문, 기호 2페이지, 숫자 줄, 이모티콘
- 키 위의 작은 기호를 길게 눌러 입력(대체 문자), 키를 뗄 때 입력, 키 미리보기
- 툴바: 이모티콘 / 클립보드 / 음성 입력(브라우저 지원 시) / 설정 / 숨기기
- 키보드가 열리면 뒤로 버튼이 키보드 숨기기(∨)로 바뀜

## 클립보드

- 텍스트를 길게 누르거나 우클릭: 잘라내기 / 복사 / 붙여넣기 / 모두 선택 / 클립보드
- 키보드 클립보드 패널(눌러서 붙여넣기, 고정, 삭제), 클립보드 앱, 기기 클립보드와 연동

## 앱

전화, 메시지(자동 답장·AI 답장 제안), 연락처, 통역, 노트, 계산기, 시계(알람·세계 시각·스톱워치·타이머), 캘린더, 갤러리, 카메라(실제 카메라), 날씨(Open-Meteo 실시간 날씨, 현재 위치), 설정, 클립보드, 인터넷

**설정**은 One UI 메뉴 구조를 따릅니다: 연결(Wi-Fi 목록), 소리 및 진동(소리 모드·음량), 알림, 디스플레이(라이트/다크·밝기·편안하게 보기·글자 크기), 배터리(실제 배터리), 배경화면 및 스타일(색상 팔레트), 홈 화면, 잠금화면, 디바이스 케어, 애플리케이션(앱 정보·강제 종료), 일반(키보드·24시간 형식·초기화), 접근성, 소프트웨어 업데이트, 휴대전화 정보, 설정 검색.

모든 데이터는 브라우저의 localStorage에 저장됩니다.

## 단축키 (PC)

- `Esc`: 뒤로
- 잠금 화면에서 `Enter` / `Space`: 잠금 해제
- 계산기 앱에서 숫자·연산자 키 입력
