# Galaxy OS 1.0

브라우저에서 바로 동작하는 휴대전화 OS 시뮬레이터입니다. `index.html` 파일 하나로 구성되어 있으며, 별도의 설치나 서버 없이 파일을 열기만 하면 됩니다.

## 주요 기능

- **Galaxy 키보드**: 한글 두벌식 조합(겹받침·이중모음·받침 분리, 자모 단위 지우기), 영문(Shift / 두 번 누르면 대문자 고정), 기호 2페이지, 숫자 줄, 이모티콘, 한/영 전환, ⌫ 길게 눌러 연속 삭제, 키 미리보기·진동·소리 설정
- **클립보드**: 텍스트를 길게 누르거나 우클릭하면 잘라내기 / 복사 / 붙여넣기 / 모두 선택 / 클립보드 메뉴, 키보드의 클립보드 패널(눌러서 붙여넣기, 고정, 삭제), 클립보드 앱, 기기 클립보드와 연동
- **앱스 화면**: 홈 화면에서 위로 밀기(또는 ^ 버튼), 앱 검색(초성 검색 지원), 길게 눌러 홈 화면에 추가
- **시스템**: 부팅 화면, 잠금 화면, 알림창·빠른 설정(위에서 아래로 밀기 또는 상태 표시줄 누르기), 헤드업 알림, 최근 앱(앱 미리보기, 위로 밀어 닫기), 뒤로/홈/최근 앱 버튼, 전원 버튼, 다크 모드, 밝기, 배경화면
- **앱**: 전화, 메시지(자동 답장), 연락처, 노트, 계산기, 시계(알람·세계 시각·스톱워치·타이머), 캘린더, 갤러리, 카메라(실제 카메라 사용), 설정, 클립보드, 인터넷

모든 데이터는 브라우저의 localStorage에 저장됩니다. 설정 › 모든 데이터 초기화로 처음 상태로 돌아갈 수 있습니다.

## 단축키 (PC)

- `Esc`: 뒤로
- 잠금 화면에서 `Enter` / `Space`: 잠금 해제
- 계산기 앱에서 숫자·연산자 키 입력 가능
